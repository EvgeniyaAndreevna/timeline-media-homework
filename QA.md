# Проверка Timeline

После `npm.cmd install` и `npm.cmd start`:

1. **Текст:** введите заметку и нажмите Enter. Разрешите геолокацию — должна появиться новая запись сверху с координатами.
2. **Ручные координаты:** запретите доступ к местоположению. Введите `ошибка` — поле должно показать ошибку. Исправьте на `[51.50851, −0.12572]` — запись должна сохраниться.
3. **Аудио:** нажмите микрофон, разрешите доступ, подождите 2–3 секунды, нажмите ✓. Запись появляется в ленте со звуковым плеером.
4. **Видео:** нажмите камеру, разрешите доступ, подождите, нажмите ✓. Во время записи видео видно без дублирования звука; в ленте появляется видеоплеер.
5. **Отмена:** начните новую аудио- или видеозапись, нажмите ✕. Новая запись не должна появиться.
6. **Фильтры:** переключайте «Текст», «Аудио», «Видео». Видны только записи выбранного типа.
7. **Обновление:** после F5 лента станет пустой. Это ожидаемо: данные находятся только в памяти.
8. **Тесты:** `npm.cmd test` — 18 проверок функции `parseCoordinates`.
9. **Сборка:** `npm.cmd run build` — создаётся папка `dist/`.
10. **GitHub Pages:** после деплоя проверьте страницу по HTTPS и работу разрешений в вашем браузере.

Внешний сервер, API, БД, localStorage и загрузка файлов отсутствуют по условиям задания. Запись мультимедиа требует физической камеры/микрофона и разрешений браузера.
